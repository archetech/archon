# v0.13 release readiness

Saved 2026-09-22 after the release-priority review. Issue #1258 is complete
through #1259 and #1260; the wallet repair UI was tested on the local node.

## Recommended order

1. **#1126 — internal Keymaster L402 exemption (merged in #1261).** Let holders of
   the configured admin key use protected Drawbridge routes without paying
   their own node. Wire both Keymaster service runtimes and test unauthenticated
   and invalid-key requests still follow normal L402 payment handling.
2. **#944 — server-side DNS rebinding protection (merged in #1262).** Node and Python
   validate the actual connection destination; browser limitations are documented.
3. **#915 — dead onion endpoint detection (merged in #1263).** Drawbridge checks
   published onion reachability through Tor and reports it separately from
   service readiness.
4. **#1128 — current protocol examples.** Generate a correctly signed current-suite
   example, preserving the consistency of signatures, CIDs and predecessor links.

**#1114 needs a compatibility decision before release**, not an unapproved
credential-acceptance change. Review together with #1090; reproduce the concrete
legacy-proof behavior and distinguish it from generic proof-set policy.

**#1156 remains paused.** Ship the DID repair tools in v0.13 and allow existing
agents time to upgrade. Gatekeeper authorization-relationship enforcement and
its historical compatibility policy are a separate later decision.

The user authorized #1126 and then #944, and asked to remember the remaining recommendations;
this list does not authorize implementing the other items automatically. Prefer
bounded release fixes over reopening the completed convergence work (#1247).

## Validation discipline

Run dependency installs, builds and tests sequentially on the shared host, check
load first, and stop task-owned work if load rises sharply. Use CI for broad
platform coverage; do not start parallel Docker builds or storage scans.
