# Archon promo video

A 30-second, 1920×1080, 60 fps promotional video in which every frame and every
sound is generated by code: no video editor, stock footage or audio samples.

- `page.html` draws any frame with `render(t)` on a canvas. The scenes are timed in
  bars of the soundtrack (128 bpm), so cuts land on the beat.
- `audio.mjs` synthesizes `soundtrack.wav` (48 kHz stereo): kick, hats, claps, bass,
  plucked arpeggio, pads, risers and impacts over Am–F–C–G.
- `render.mjs` loads the page in headless Chrome, captures each frame through the
  DevTools protocol and pipes them to ffmpeg with the soundtrack.

## Build

Requires Node 22+, ffmpeg, and a Chrome or `chrome-headless-shell` binary.

```sh
node audio.mjs                                     # → soundtrack.wav
CHROME=/path/to/chrome node render.mjs video       # → archon-promo.mp4 (~3 min)
CHROME=/path/to/chrome node render.mjs stills 8 24 # → still-8.png, still-24.png
```

Outputs are git-ignored.
